# Obital documentation

The repository documentation is grouped by purpose:

| Folder | Contents |
| --- | --- |
| [`architecture/`](architecture/) | System architecture and data-processing flow |
| [`planning/`](planning/) | Product requirements, technical plan, stack, and workflow |
| [`product/`](product/) | The extended Obital product guide |
| [`testing/`](testing/) | Test strategy, manual system cases, and user-testing evidence |
| [`reviews/`](reviews/) | Code reviews, risk summaries, and remediation history |
| [`engineering/`](engineering/) | Coding standards and implementation conventions |
| [`screenshots/`](screenshots/) | Screenshots referenced by the product guide |
| [`archive/`](archive/) | Superseded design documents, kept for provenance |

The root [`README.md`](../README.md) is the shortest onboarding path. Historical references should point to the grouped documents above rather than adding new root-level files.
